# 의존성

[English](dependencies.md).

모든 의존성은 선언한 런타임 범위(`package.json`의 `engines`와 `.php-version`의 하한인 Node.js 26.12.0, PHP 8.4)를 지원하는 최신 안정 버전을 사용한다. 정확한 버전 고정은 그 이유와 고정을 해제하는 조건을 기록한다.

2026-10-28 검토는 `eventsource-parser` 4.1.3, `phpstan/phpstan` 2.3.3, `phpunit/phpunit` 13.4.5, `setuptools` 84.2.1과 ruff 0.17.3을 해석한다. Composer release lock은 PHP 8.4.1 platform을 사용하고 검증은 PHP 8.4.27에서 실행한다.

## PHP 8.4 archive 호환성

Template PHP archive 0.0.15는 PHP >=8.4를 요구하며 SHA-256은 `d14ae96be8bbe90ee657237924bb17c8af9173eb991c16f3afdd481009ba2a9e`, SHA-1은 `9696031777f784116bb2236b70d209203ef7a0e2`이다. 두 release Composer lock은 PHP 8.4.1 platform에서 이 공개 archive를 해석한다. 검증 runtime은 PHP 8.4.27이며 library 최소 요구사항은 >=8.4로 유지한다. Native source 개발은 별도 manifest, lock과 설치 기록을 사용한다. Archive consumer 검증은 개발 link가 없는 배포 graph를 사용한다.

## multipart 파서

각 서버는 `multipart/form-data` 본문을 자체 파서로 읽으며, 그 파서는 HY-57, HY-113, HY-42를 지켜야 한다. 이 절은 각 생태계의 관리되는 파서를 여기 적은 버전의 소스로 이 규칙들과 대조한 기록이다(H26.3). 대조는 패키지의 소스를 읽었고 어떤 패키지도 설치하지 않았으므로 lock과 검토 기록은 바뀌지 않았다. 후보 중 어느 것도 규칙을 지키지 않으므로 각 서버는 자신의 파서를 유지한다. 다른 PHP 패키지는 대조하지 않았다.

| 서버 | 현재 파서 | 후보와 버전 | 결과와 이유 | 교체의 조건 |
|---|---|---|---|---|
| PHP | `packages/server/php/src/Multipart.php`의 `Multipart::read`, `Fields.php`가 호출한다 | `riverline/multipart-parser` 2.2.2(MIT, 2026-01-15 배포) | 유지. part의 본문을 `Content-Transfer-Encoding`으로 디코딩하는데(`src/StreamedPart.php`의 `getBody`, base64와 quoted-printable), HY-57은 part의 내용을 있는 그대로 읽는다. header 값을 MIME word로 디코딩하고(`mb_decode_mimeheader`, 107행), `Content-Disposition`의 옵션을 모든 `;`에서 나누므로(`parseHeaderContent`, 394행) 인용된 filename 안의 `;`에서 잘리며, `filename*` 값이 filename을 대신하는데(403행) HY-113은 추가 디코딩을 금한다. | part의 내용, header 값, 옵션을 있는 그대로 유지하는 버전. |
