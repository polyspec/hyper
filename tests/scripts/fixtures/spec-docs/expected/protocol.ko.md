# 픽스처 프로토콜

<!-- contracts/protocol.json에서 생성됨. 직접 수정하지 않는다. -->

픽스처는 프로토콜 하나를 적는다. 문서는 생성기가 쓴다.

## 개요

- 첫 항목이다.
- 둘째 항목이다.

  중첩된 문단이다.

## 규칙

- **HY-1** <a id="HY-1.1"></a> 규칙은 문장 하나를 적는다. <a id="HY-1.3"></a> 번호 2는 폐기되었다.

  1. <a id="HY-1.4"></a> 순서 있는 항목이다.

  ```json
  {"a": 1}
  ```

- **HY-2** <a id="HY-2.1"></a> 둘째 규칙은 문장 하나를 가진다.

## 표

| 이름 | 뜻 |
| --- | --- |
| `a` | 첫째 |
